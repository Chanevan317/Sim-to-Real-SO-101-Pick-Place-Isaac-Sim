# Review recordings

A small web page to check `.h5` recordings before converting them: watch both cameras, look at
the joints, flag bad tries and move them to a trash folder. Works in `lerobot_env` or
`env_isaaclab`.

| File | What it does |
|---|---|
| `review_data.py` | Starts the page on http://127.0.0.1:8000 |
| `review_data.html` | The page itself |

Guide: [Review your recordings in the browser](../../docs/2_record_demos.md#review-your-recordings-in-the-browser)
